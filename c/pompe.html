Pompe

Faire respirer une nappe ou une basse sous la grosse caisse, sans signal externe à brancher.

Télécharger ComicsToute la gamme Comics

Le son

Ce que ça change dans votre morceau

Pompe reproduit le pompage du sidechain, calé sur le tempo, sans qu’il faille brancher un signal externe. La forme est dessinée (pompe, sinus, carré, scie), ou le son passe d’une oreille à l’autre en auto-pan.

Vitesse, profondeur, forme, décalage, lissage, auto-pan : six réglages pour donner du mouvement à une nappe, une basse ou un accord.

♪
Démo audio bientôt

Trois points forts

Un sidechain sans câblage

Le pompage se cale sur le tempo.

Des formes dessinées

Pompe, sinus, carré, scie.

Un auto-pan

Le son passe d’une oreille à l’autre.

Mode d’emploi

Comment l’utiliser

Placez-le sur une nappe ou une basse. Réglez la vitesse pour qu’elle suive le tempo, la profondeur pour le creux, puis la forme. Le décalage place le creux sur le temps. Le lissage arrondit les bords.

Pour un auto-pan, activez-le.

Des idées pour démarrer

  • Nappe : pompe lente, profondeur moyenne.
  • Basse 808 : forme carrée, décalage sur le temps.
  • Accords : sinus.
  • Voix : auto-pan léger.

Les réglages

Ce que fait chaque réglage

Vitesse
La rapidité du pompage.
Profondeur
Le creux du volume.
Forme
Pompe, sinus, carré, scie.
Décalage
Place le creux dans le temps.
Lisse
Arrondit les bords de la forme.
Auto-pan
Le mouvement gauche-droite.

Pour qui

Quand le sortir

Pour les nappes et les basses qui doivent respirer avec la grosse caisse : trap, électro, house.
