VST3 ou Audio Unit (AU) sur Mac : quelle différence, lequel choisir ?

Sur Mac, un plug-in audio existe en plusieurs formats. Les deux plus répandus sont le VST3 et l’Audio Unit (AU). Voici ce qui les distingue et comment savoir lequel utiliser avec votre logiciel de musique.

Le principe

Un plug-in est un petit programme (instrument ou effet) qui se charge dans votre logiciel de musique, le « DAW ». Chaque logiciel accepte certains formats, pas tous. Un même plug-in est donc souvent livré en plusieurs formats pour fonctionner partout.

Audio Unit (AU)

L’Audio Unit est le format d’Apple. Il est intégré à macOS et pris en charge par les logiciels d’Apple : Logic Pro, GarageBand et MainStage. Logic Pro n’accepte que l’Audio Unit : si vous travaillez avec Logic, c’est le format à installer.

VST3

Le VST3 est la version actuelle du format créé par Steinberg. Il est accepté par la plupart des logiciels tiers : Ableton Live, Studio One, Reaper, Bitwig, FL Studio sur Mac, Cubase.

Quel logiciel accepte quel format ?

  • Logic Pro, GarageBand, MainStage : Audio Unit.
  • Ableton Live : Audio Unit et VST3.
  • Studio One : Audio Unit et VST3.
  • Reaper : Audio Unit et VST3.
  • FL Studio (Mac) : Audio Unit et VST3.
  • Bitwig Studio : VST3.
  • Cubase : VST3.
  • Pro Tools : uniquement AAX, un format que les plug-ins BrickS Forge ne proposent pas.

Vérifiez toujours dans la documentation de votre logiciel : les prises en charge évoluent avec les versions.

Dois-je choisir l’un ou l’autre ?

Non : les plug-ins BrickS Forge installent les deux formats ensemble. Votre logiciel voit celui qu’il comprend. Si votre logiciel accepte les deux (Ableton Live, Studio One, Reaper), les deux marchent ; choisissez celui que vous préférez et gardez-le d’un projet à l’autre.

Où sont installés les plug-ins ?

  • Audio Unit : /Library/Audio/Plug-Ins/Components
  • VST3 : /Library/Audio/Plug-Ins/VST3

Après l’installation, relancez votre logiciel et lancez un nouveau scan des plug-ins si besoin.

Questions fréquentes

Logic Pro accepte-t-il le VST3 ?

Non, Logic Pro n’accepte que l’Audio Unit. Installez le format AU.

Quel format sonne le mieux ?

Aucun : le son est identique. Le format ne change que la façon dont le logiciel charge le plug-in.

Un plug-in VST3 fonctionne-t-il sur les Mac Apple Silicon ?

Oui, à condition que le plug-in soit compilé pour Apple Silicon. Les plug-ins BrickS Forge sont universels : Apple Silicon et Intel.
