Le son

Ce que ça change dans votre morceau

CHRONOS est un délai à douze machines. Numérique pour des répétitions propres, bande qui s’use et qui flotte, seaux pour le côté lo-fi, double et ping-pong pour la largeur, inverse pour les arrivées à l’envers, gonflé quand les répétitions montent… On change de machine, on change d’humeur, sans changer de plug-in.

Les réglages sont les mêmes pour toutes les machines : le temps, le nombre de répétitions, le filtre, du grain pour salir, une vitesse et une profondeur de modulation. Le temps se cale sur le tempo du projet par une subdivision (noire, croche pointée, croche, triolet, double) ou se règle librement.

Trois points forts

Mode d’emploi

Comment l’utiliser

Choisissez la machine selon le rôle : Digital pour un écho transparent, Bande ou Seaux pour du caractère, Ping-pong pour élargir, Inverse pour annoncer un mot. Réglez ensuite la subdivision pour que l’écho tombe sur le tempo, puis le nombre de répétitions.

Pour la saleté, montez Grain et baissez Filtre. Pour du mouvement, passez par Vitesse et Profondeur. Dosez avec Mix : un écho qui accompagne, pas qui noie.

Des idées pour démarrer

  • Voix de trap : machine Ping-pong, subdivision croche pointée, mix bas, filtre légèrement fermé.
  • Caisse claire boom bap : machine Bande, une seule répétition, grain léger.
  • Transition de break : machine Inverse, répétitions hautes, mix qui monte.
  • Texture lo-fi : machine Lo-fi, vitesse basse, profondeur moyenne.

Les réglages

Ce que fait chaque réglage

Machine
Choisit le caractère : digital, bande, seaux, double, ping-pong, inverse, gonflé, duck, trémolo, filtre, lo-fi, motif.
Temps
Durée entre deux répétitions, quand on ne se cale pas sur le tempo.
Subdivision
Cale l’écho sur le tempo : noire, croche pointée, croche, triolet, double croche.
Répétitions
Combien de fois l’écho se répète avant de s’éteindre.
Filtre
Assombrit les répétitions pour qu’elles s’effacent derrière la source.
Grain
Ajoute de la saleté aux répétitions.
Vitesse / Profondeur
Modulent la hauteur de l’écho pour un effet de bande qui flotte.
Largeur
Ouvre ou resserre l’image stéréo des répétitions.
Mix / Niveau
Mix dose l’effet par rapport au son d’origine ; Niveau règle la sortie.

Pour qui
