Le son

Ce que ça change dans votre morceau

DYNAMO est un compresseur numérique à huit styles : transparent, classique, optique, voix, master, bus, punch, pompe. Avec genou, plage, anticipation et filtres de chaîne latérale, il couvre presque tous les usages.

Chaque style change le comportement de l’attaque et du relâchement, comme si on changeait de machine. Un seul plug-in pour une session entière.

Mode d’emploi

Comment l’utiliser

Choisissez le style selon l’usage, puis le seuil et le rapport. Ajustez le genou pour une compression plus douce ou plus franche. Utilisez les filtres latéraux si la basse fait pomper l’ensemble.

Pour un bus de batterie, essayez punch ; pour une voix, le style voix.

Des idées pour démarrer

  • Voix : style voix, 3 dB de réduction.
  • Bus de batterie : punch, attaque lente.
  • Master : style master, réduction légère.
  • Basse : style optique, genou doux.

Ce que fait chaque réglage

Style

Seuil / Rapport

Attaque / Relâche
La vitesse de la compression.
Genou
Compression progressive ou franche.
Plage
Limite la quantité de réduction.
Anticipation
Le plug-in regarde un peu en avant pour attraper les pics.
Filtres latéraux
Filtrent le signal qui déclenche la compression.
