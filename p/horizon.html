Le son

Ce que ça change dans votre morceau

HORIZON est un delay de studio : de 20 millisecondes à douze secondes, avec tap et subdivisions. Huit machines : numérique, bande, ping-pong, multi à quatre échos, rythme, inverse, shimmer, diffus. Des échos qui s’étirent jusqu’à l’horizon.

Filtre, graves, grain, diffusion, profondeur, vitesse, hauteur (±12 demi-tons), largeur, duck et gel : de quoi façonner n’importe quel écho.

Mode d’emploi

Comment l’utiliser

Choisissez une machine selon l’usage, puis le temps (ou la subdivision pour caler sur le tempo). Réglez les répétitions, le filtre et le grain. Utilisez le duck pour que l’écho s’efface quand la voix chante.

Le gel fige l’écho : utile pour les transitions.

Des idées pour démarrer

  • Voix de trap : ping-pong, croche pointée, duck moyen.
  • Caisse claire : bande, une répétition.
  • Break : inverse, mix qui monte.
  • Nappe : shimmer, hauteur +12, diffusion haute.

Les réglages

Ce que fait chaque réglage

Machine
Numérique, bande, ping-pong, multi, rythme, inverse, shimmer, diffus.
Temps / Subdivision
La durée entre échos, libre ou calée sur le tempo.
Répétitions
Combien de fois l’écho se répète.
Filtre / Graves / Grain
Colorent et salissent les répétitions.
Diffusion / Profondeur / Vitesse
Étalent et font bouger les échos.
Hauteur
Transpose les échos de ±12 demi-tons.
Duck
Baisse l’écho quand le son d’origine joue.
Gel
Fige l’écho en cours.
